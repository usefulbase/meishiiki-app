# メガネ明視域計算アプリ

眼鏡店スタッフ向けに、完全矯正値・処方値・加入度・調節力から、メガネ装用時の明視域を確認するためのWebアプリです。

店舗現場での簡易計算、処方比較、新人教育、お客様説明用の資料作成を想定しています。

---

## 公開ページ

GitHub Pages にて公開中です。

https://usefulbase.github.io/meishiiki-app/

## 主な機能

- 明視域計算
- 片眼入力 / 左右同時入力
- 単焦点 / 遠近両用 / 中近・室内用レンズ対応
- 加入度 ADD 対応
- フィッティングポイント（FP）加入変化率対応
- 中近レンズ用FPプリセット対応
  - 中近（遠方重視）25%
  - 中近（近方重視）40%
  - 任意入力
- FP任意入力値の保持
  - 手入力した数値は勝手に補正しない
  - 新規処方案のFP初期値は40%
- 調節力の実測値入力
- 年齢からの調節力目安計算
  - 年齢別目安
  - Hofstetter最小値
- 年齢別調節力目安表の折りたたみ表示
- 使用する調節力の切り替え
  - 100%
  - 2/3
  - 1/2
- 処方案A〜Cの比較
- 処方案ごとの調節力・使用調節力管理
- 比較シミュレーション
  - 調節力使用率の比較
  - 加入度変更シミュレーション
  - FP変化率シミュレーション
- メイン画面でのレンズイラスト表示
- 遠近 / 中近の見え方イメージ表示
- スマホ用独自テンキー
- 入力クリア機能
- PDF保存機能
- PDFは使用している処方案数に応じてページ数を自動調整
- 片眼入力時はPDFも片眼のみ出力

## 想定用途

- 店舗での明視域の簡易確認
- 遠近・中近・単焦点の見え方比較
- 加入度やFP位置による見え方の違いの説明
- 調節力の使い方による明視域差の教育
- 処方案A/B/Cを使った比較説明
- 新人スタッフへの教育
- お客様向けの簡易PDF資料作成

## 使い方

1. 入力モードを選択します。
   - 片眼入力
   - 左右同時入力
2. 完全矯正値（7A）を入力します。
3. 処方値を入力します。
4. レンズタイプを選択します。
   - 単焦点
   - 遠近両用
   - 中近・室内用
5. 必要に応じて加入度 ADD やFP加入変化率を入力します。
6. 調節力を設定します。
   - 実測値を使う
   - 年齢から計算する
7. 使用する調節力を選択します。
8. 計算結果・イラスト・明視域を確認します。
9. 必要に応じて比較シミュレーションを確認します。
10. 必要に応じてPDF保存を行います。

## 処方案A〜Cについて

処方案A〜Cを追加して、複数の処方パターンを比較できます。

各処方案ごとに以下を保持します。

- 処方案名
- レンズタイプ
- 加入度 ADD
- FP加入変化率
- 右眼処方値
- 左眼処方値
- 調節力モード
- 実測調節力
- 年齢
- 年齢計算方式
- 使用する調節力

これにより、同じ度数でも「調節力をどの程度使うか」によって、明視域がどう変わるかを比較できます。

処方案を使わない場合は削除でき、再追加時はA/B/Cの順番に整理されます。

---

## 比較シミュレーションについて

計算結果の下に、折りたたみ式で比較シミュレーションを表示できます。

表示内容はレンズタイプによって変わります。

### 単焦点

- 調節力使用率の比較

### 遠近両用

- 調節力使用率の比較
- 加入度変更シミュレーション

### 中近・室内用

- 調節力使用率の比較
- 加入度変更シミュレーション
- FP変化率シミュレーション

比較シミュレーションも計算上の目安であり、実際の見え方を保証するものではありません。

## 年齢別調節力目安について

年齢から調節力を計算する場合、以下の方式を選択できます。

- 年齢別目安
- Hofstetter最小値

年齢別目安は、以下の表を基準にしています。

| 年齢 | 調節力目安 |
|---:|---:|
| 10歳 | 12.00D |
| 20歳 | 8.50D |
| 30歳 | 7.00D |
| 40歳 | 4.50D |
| 45歳 | 2.50D |
| 50歳 | 1.50D |
| 55歳 | 1.00D |
| 60歳 | 0.50D |
| 65歳 | 0.25D |
| 70歳以上 | 0.00D |

表にない年齢は、前後の値から線形補間します。

70歳以上は0.00Dとして扱います。

Hofstetter最小値は以下の式で計算します。

```text
15 − 0.25 × 年齢
```

## 入力クリアについて

上部の「入力クリア」ボタンで、画面上の入力内容を初期状態に戻せます。

誤操作防止のため、実行前に確認ダイアログを表示します。

クリアされる主な内容：

- 入力モード
- 処方案A〜C
- レンズタイプ
- 加入度
- FP加入変化率
- 完全矯正値
- 処方値
- 調節力
- 年齢
- 使用する調節力

## PDF出力について

PDF保存では、お客様説明向けに簡潔な内容を出力します。

表示内容の例：

- 処方案名
- レンズタイプ
- 加入度
- 使用調節力
- 調節力計算
- FP加入変化率
- 7A
- 処方値
- レンズイラスト
- 明視域の目安

処方案Aのみ使用している場合は1ページ、A/Bを使用している場合は2ページ、A/B/Cを使用している場合は3ページ出力されます。

片眼入力時は、選択中の片眼のみPDFに出力されます。

## 注意事項

- 本アプリは計算補助ツールです。
- 明視域は理論値であり、実際の見え方を保証するものではありません。
- 実際の処方・販売判断は、視力測定結果、装用状況、生活環境、使用目的、フレームフィッティング、レンズ設計などを総合的に考慮してください。
- 調節力を年齢から算出する場合は、あくまで目安値です。
- お客様説明に使用する場合は、必要に応じて口頭で補足してください。
