# meishiiki-app

# メガネ明視域計算アプリ

眼鏡店スタッフ向けの  
「明視域」「調節力」「加入度」の計算をサポートするWebアプリです。

スマホでも使いやすいように設計しており、店舗現場での簡易計算を想定しています。

---

## 主な機能

- 明視域計算
- 遠近両用 / 中近レンズ対応
- フィッティングポイント（FP）対応
- Hofstetter最小値対応
- 石原式対応
- スマホ用テンキー搭載
- イラスト表示対応

---

## 使い方

1. 必要項目を入力
2. 計算方式を選択
3. 「計算」ボタンを押す
4. 明視域などを表示

---

## 注意事項

- 本アプリは計算補助ツールです
- 実際の処方・販売判断は各種検査結果をもとに行ってください
- 計算結果を完全保証するものではありません
